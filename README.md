# 📌 CRUD приложение с использованием логирования через AOP

## 📖 Описание
Данное приложение представляет собой простой RESTful сервис для управления задачами.

Сущность задачи:

Task { Long id; String title; String description; Long userId; }

---

## 📌 Реализованные REST эндпоинты

| HTTP Method | Endpoint       | Описание                          |
|------------ |--------------- |-----------------------------------|
| **POST**    | `/tasks`       | Создание новой задачи             |
| **GET**     | `/tasks/{id}`  | Получение задачи по ID            |
| **PUT**     | `/tasks/{id}`  | Обновление задачи                 |
| **DELETE**  | `/tasks/{id}`  | Удаление задачи                   |
| **GET**     | `/tasks`       | Получение списка всех задач       |

---

## 📌 AOP (Аспекты) для логирования

В приложении реализован класс `Aspect`, содержащий следующие виды advice для логирования:

| Advice            | Описание                                                                 |
|-------------------|--------------------------------------------------------------------------|
| `@Before`         | Логирование перед выполнением метода                                     |
| `@AfterReturning` | Логирование успешного завершения метода и результата                     |
| `@AfterThrowing`  | Логирование в случае возникновения исключения в методе                   |
| `@Around`         | Замер времени выполнения метода и логирование результата                 |

✅ Для каждого типа Advice реализован отдельный метод.  
✅ Допускается использование нескольких advice на отдельные методы.  
❌ Меньше четырех типов advice — запрещено по условию задания.

---

## 📌 Цели проекта
- Реализация полноценного CRUD REST API на Spring Boot
- Практика использования AOP (Aspect-Oriented Programming)
- Логирование жизненного цикла выполнения методов
- Работа с аннотациями `@Aspect`, `@Before`, `@AfterReturning`, `@AfterThrowing`, `@Around`
